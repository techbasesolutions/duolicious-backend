## What the reviews caught

Drawn from the ledger (`progress.md`) and the task reports' own "what the gate caught" sections:

- **The renderer's caption clamp was inert.** `lineClamp` in satori only takes effect on a `display: 'block'` element; the caption band had no explicit display and a long caption ran to a third line, pushing the whole foot block up. Caught by a probe over five caption lengths (a 102-character caption that fit in two lines anyway proved nothing; a 115-character one caught it), fixed with one property, and locked with a regression test that renders one-line, two-line and 115-character captions and asserts the name band never moves.
- **Hebrew names rendered backwards.** Satori draws characters in the order given with no bidirectional algorithm, so the first render put the first Hebrew letter leftmost. Caught by cropping and zooming the name band rather than trusting the thumbnail. Fixed by an explicit run-reversal (`visualOrder`) that resolves runs the way a right-to-left paragraph would, keeping digit and Latin runs in reading order.
- **The Growth tab offered actions the API refuses.** Reschedule was offered on a `review` row (the API's `TRANSITIONS` table has no path from `review` through reschedule), Approve on `awaiting_render` (which cannot reach `scheduled`), and Cancel on `processing` (a row with a call already in flight). Caught by the task review reading `service/spotlight/queue.py`'s own state machine against the menu's gating, not by exercising the UI. Fixed by moving the gating into a pure, tested `queueMenu(card)` helper that mirrors `TRANSITIONS` exactly, and by adding a Retry action so a `failed` card had a working action at all.
- **The Growth tab had no error states.** Every query (`useGrowthStats`, `useGrowthQueue`, `useTokenHealth`, `useRemovals`) read a failed fetch as an empty success: a dead token-health endpoint would have shown "Token invalid" (a false positive) rather than "could not load", and a dead queue endpoint would have shown "nothing in the queue" rather than an error. Fixed with a neutral "unknown" state for the token chip and an explicit `isError` empty state per section, following the convention already used elsewhere in the admin app (`tab-audit.tsx`, `tab-cohorts.tsx`).
- **The Yoruba name fell out of the display font and left a visible gap**, because Ultra has no Latin Extended Additional glyphs and satori drops a whole word to the fallback face when one character is missing. Fixed by decomposing only the specific code points Ultra lacks, so the base letters stay in Ultra and only the diacritic falls back.
- **A shared token bug made every admin tab render wrong colours.** `globals.css` declared `--card`, `--muted` and `--border` twice inside `:root`, and the build's trailing `@supports` block re-emitted the oklch copies last, so they always won the cascade: panels rendered indigo and muted text near black on every tab, not only Growth. Found while building the Stats section (numbers were unreadable), fixed by removing the duplicates, and disclosed as a change outside the brief's file list because the fix touches shared chrome.
